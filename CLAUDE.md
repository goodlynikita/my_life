# YOU: правила проекта для Claude

Этот файл Claude читает в начале каждой сессии. Здесь договорённости, которые нельзя забывать.

## Владелец и общение
- Владелец: Ник. Пиши по-русски, на «ты», коротко и по делу, без воды.
- Всё техническое (консоли, настройки, деплой) объясняй пошагово, «носом тыкнуть»: куда нажать, что выбрать, что вставить. Не рассчитывай на знание терминов.
- Перед большими изменениями коротко скажи, что собираешься сделать.
- **Некритичные мелочи (запятая не там, отступ, цвет, формулировка) сразу НЕ чинить и не тратить на них работу.** Коротко подтвердить и записать в раздел «Список мелочей» ниже. Чинить сразу только то, что ломает работу: данные, деньги, вход, падения.
- После работы кратко: что изменилось и что проверить руками. Без пересказа процесса.

## Что это за проект
PWA «YOU»: трекер жизни (тренировки, привычки, финансы, цели) + кабинет тренера.
- `index.html`: само приложение YOU (SPA на чистом JS, без сборщика).
- `coach.html`: кабинет тренера. План клиента в нём рисуется тем же кодом, что и в YOU (`js/screens/training.js`), через `window.__coachMode` и подмену `Store` на данные клиента.
- `admin.html`: админка. `start.html`: лендинг.
- Вход тренера: на экране входа YOU сверху выбор «Занимаюсь сам / Я тренер» (`.lg-role`, «Я тренер» ведёт на `coach.html?reg=1`, там сразу открыта регистрация); в меню «···» у всех пункт «Я тренер: создать кабинет» (у тренеров «Кабинет тренера»); если email уже есть в YOU, регистрация в кабинете сама переключает на вход с подсказкой; кнопки для тренеров на лендинге тоже на `?reg=1`.
- Данные: Firebase Realtime Database, проект `nik-track`. Корень данных владельца: `nik-data`.
- AI-тренер: облачная функция Yandex Cloud `ai-coach` (код в `server/yandex-ai-coach/index.js`) → YandexGPT. Адрес функции в `js/config.js` (`aiChatUrl`).
- Хостинг: you-app.ru (Yandex Object Storage). Выкладка автоматически через GitHub Actions (`.github/workflows/deploy.yml`) при пуше в `main`. Папка `server`, `*.md` и `*.zip` на сайт не попадают.
- Старый хостинг GitHub Pages (goodlynikita.github.io/my_life) ещё жив: `js/moved.js` в браузере переадресует на you-app.ru, в установленной иконке просит переустановить с нового адреса. Со временем выключить.

На компьютере две колонки. ## Обязательные правила
1. **Секреты никогда не попадают в код и в репозиторий.** Ключи Firebase DB secret, Yandex static key и т.п. живут только в переменных окружения функции в Yandex Cloud и в Secrets GitHub. Если видишь секрет в коде или в чате, предупреди и не коммить.
2. **В текстах интерфейса нельзя длинное тире «—».** Используй точку, запятую, двоеточие.
3. **Пояснения не выводим на экран.** Описания и инструкции убираем в подсказки (`Tour`, кнопка «?»). На экране только данные и действия.
4. **Обращение к пользователю на «ты»** (в кабинете тренера к тренеру на «вы»).
5. **После любых изменений в js/css/html повышай версию кэша** в `sw.js` (`const CACHE = 'nik-system-vNNN'`, +1), иначе у людей останется старая версия.
6. **Firebase rules** присылай Нику всегда полным текстом, не кусками.
7. Пользовательский текст (заметки, названия упражнений, траты) всегда экранировать перед вставкой в HTML.
8. Не ломать совместимость данных: старые поля не удалять, новые добавлять так, чтобы старые записи читались.
9. Тренер в кабинете пишет клиенту только изменённые дни плана (точечные пути), а не весь план целиком: иначе затираются свежие записи клиента.

## Как работать
- Перед правкой прочитай нужный файл целиком или нужный кусок, не правь вслепую.
- Проверяй в браузере (Playwright/Chromium) ключевые сценарии и смотри скриншоты: телефон 375×812, ошибок в консоли быть не должно.
- `node --check` для каждого изменённого JS-файла.
