5. Порядок и условия обработки

  1. Обработка осуществляется автоматизированным способом и включает сбор, запись, систематизацию, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передачу (предоставление, доступ), блокирование, удаление и уничтожение.
  2. Доступ к данным раздела тренировок получает только тренер, которому Пользователь сам выдал ключ доступа или по ссылке которого подключился. Пользователь может отключить тренера в любой момент.
  3. Для хранения данных и работы Сервиса Оператор привлекает следующих лиц, обрабатывающих данные по поручению Оператора или предоставляющих ему технические услуги:

    • GitHub, Inc. (88 Colin P Kelly Jr St, San Francisco, CA 94107, USA), сервис GitHub Pages: размещение страниц Сервиса;
    • при обращении в поддержку через Telegram: мессенджер Telegram, переписка ведётся по инициативе Пользователя.
  4. В связи с этим осуществляется трансграничная передача персональных данных на территорию США. Пользователь даёт согласие на такую передачу в тексте согласия.
  5. Сроки обработки: до достижения целей обработки, удаления учётной записи или отзыва согласия. После этого данные уничтожаются в срок не более 30 дней, если иное не предусмотрено законом. Данные в хранилище браузера Пользователь может удалить сам, очистив данные сайта.
  6. Сервис не использует файлы cookie для рекламы и сторонних счётчиков посещаемости. Хранилище браузера используется для работы приложения: вход, настройки, тема оформления.

6. Права субъекта персональных данных

Субъект вправе:

  • получать сведения об обработке своих персональных данных (ч. 7 ст. 14 Закона);
  • требовать уточнения, блокирования или уничтожения данных, если они неполные, устаревшие, неточные или не нужны для заявленной цели;
  • отозвать согласие на обработку персональных данных;
  • обжаловать действия Оператора в Роскомнадзоре или в суде.

Запросы направляются на nedomolkin.1998@mail.ru. Оператор отвечает в течение 10 рабочих дней с даты получения запроса. Срок может быть продлён не более чем на 5 рабочих дней с уведомлением субъекта о причинах. Отзыв согласия не влияет на законность обработки до его получения; после отзыва пользоваться Сервисом будет невозможно, так как без обработки данных он не работает.

7. Меры по защите данных

  • вход в учётную запись только по паролю, передача данных по защищённому протоколу HTTPS;
  • правила доступа в базе данных: каждый Пользователь видит только свои данные, тренер видит только раздел тренировок подключённых к нему клиентов;
  • ключ доступа для тренера одноразовый и действует 24 часа;
  • обработка минимально необходимого объёма данных, отсутствие передачи данных для рекламы;
  • назначение Оператором лица, ответственного за организацию обработки персональных данных (сам Оператор), контроль за соблюдением Политики.
